# Personal Site – Yu-Han Lee

This repository contains the source for my personal website / portfolio hosted on GitHub Pages.

## Tech Stack

- Plain HTML + CSS (no framework)
- Custom dark theme with subtle animations
- Handcrafted assets (favicons, videos, images) stored under `images/`

## Layout

- `index.html`: main page
- `stylesheet.css`: site-wide styling
- `images/`, `data/`: media and CV

## Local Preview

Serve the site with any static server. Examples:

```bash
# Python 3
python3 -m http.server 8000

# Node
npx serve .
```

Then browse to `http://localhost:8000`.

## Deployment

The site is published automatically by GitHub Pages whenever the `main` branch is updated.
